# 🇹🇭 Thailand Hotline Application
**แอปพลิเคชันศูนย์รวมหมายเลขสายด่วนฉุกเฉินแห่งประเทศไทย**

[![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)](https://flutter.dev/)
[![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)](https://dart.dev/)

แอปพลิเคชัน "สายด่วน Thailand" ถูกพัฒนาขึ้นเพื่อเป็นศูนย์กลางรวบรวมหมายเลขโทรศัพท์ที่สำคัญและจำเป็นต่อการดำรงชีวิตประจำวัน 
ครอบคลุมตั้งแต่เหตุด่วนเหตุร้าย การสาธารณสุข ไปจนถึงการติดต่อหน่วยงานภาครัฐและเอกชน 
เพื่อให้ผู้ใช้งานสามารถเข้าถึงความช่วยเหลือได้อย่างทันท่วงทีและมีประสิทธิภาพสูงสุดในทุกสถานการณ์ฉุกเฉิน

</div>

---

## ✨ Core Features (คุณสมบัติเด่นของแอปพลิเคชัน)

* 🛡️ **Comprehensive Directory:** รวบรวมเบอร์ติดต่อฉุกเฉินระดับชาติไว้อย่างครบถ้วน (อาทิ เหตุด่วนเหตุร้าย, แพทย์ฉุกเฉิน, ธนาคาร และสาธารณูปโภค)
* ⚡ **Smart One-Touch Dialing:** ระบบโทรออกอัจฉริยะ ช่วยให้ผู้ใช้งานสามารถกดโทรออกหาหน่วยงานที่ต้องการได้ทันทีเพียงปลายนิ้วสัมผัสจากภายในแอปพลิเคชัน
* 🎨 **Modern Aesthetic UI:** การออกแบบส่วนต่อประสานกับผู้ใช้งาน (User Interface) ที่ทันสมัย สะอาดตา โดยใช้โทนสีเขียวเป็นหลักเพื่อสื่อถึงความปลอดภัย ความสงบ และความสบายตา
* 🗂️ **Systematic Categorization:** จัดหมวดหมู่หมายเลขสายด่วนอย่างเป็นระบบ เพื่อประสบการณ์การค้นหาที่รวดเร็วและตรงจุด
* 👩‍💻 **Developer Profile:** หน้าต่าง About นำเสนอข้อมูลรายละเอียดของผู้จัดทำอย่างเป็นทางการสไตล์ Glassmorphism

## 🛠️ Tech Stack (เทคโนโลยีที่ใช้ในการพัฒนา)
